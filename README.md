# 晚风投递 · Night Breeze Courier

一款 90 秒、单指可玩的夜间投递街机小游戏。

**立即试玩：** https://Wangyuan-Hub.github.io/night-breeze-courier/

## 玩法

- 按住空格、鼠标或屏幕上升，松开滑翔。
- 穿过发光邮筒完成投递，连续投递最高累积 ×9 连击。
- 收集星光获得额外分数，避开会打断连击的乌云。
- 单局 90 秒，支持暂停、静音、最高分记录和移动端触控。

## 项目内容

- `index.html`：无需安装的完整可玩版本
- `design.md`：玩法、计分、难度曲线与视觉方向设计稿

## 本地运行

直接用浏览器打开 `index.html` 即可。
